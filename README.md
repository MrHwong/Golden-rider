# 🚴 Golden Rider（骑行游戏）

一只鹈鹕，一辆自行车，一条沿海公路。打开网页就能玩的 3D 休闲小游戏。

**🎮 在线试玩**：部署后此处会更新为 GitHub Pages 地址

## 玩法

- 自动前进，速度随里程越来越快
- 吃 🪙 金币 +10 分
- **加速冲刺（Shift）可以直接撞碎路障** +15 分；普通速度撞上会掉血
- 路上会刷出 🧪 血瓶，捡到回一格血（上限三格）
- 血量归零摔车结算，最高分存在浏览器本地

## 操作

| 按键 | 功能 |
|---|---|
| ← → / A D | 左右移动（手机：单指拖动） |
| Shift | 加速冲刺，撞碎路障 |
| 空格 | 跳跃，越过路障 / 接空中金币 |
| 鼠标拖拽 / 双指拖动 | 自由旋转视角 |
| 滚轮 / 双指捏合 | 缩放视角 |
| 双击画面 | 复位视角 |

## 特性

- 纯前端实现，无需下载、无需联网（Three.js 已本地化）
- PC 与手机浏览器均可游玩
- GLSL 海面着色器：多层波浪起伏、波峰浪花、近岸涌浪泡沫带、阳光反光路径
- 程序化生成的沥青/沙滩/草地纹理、弯干棕榈、海鸥、云朵等场景细节
- 最高分存 localStorage，最高分不丢失

## 本地运行

直接双击 `index.html`，或：

```bash
npx serve .        # 或任意静态服务器
```

开发调试可运行冒烟测试（需本机 Chrome）：

```bash
npm install
node smoke-test.js
```

## 技术栈

Three.js r128 · 原生 JavaScript · GLSL Shader · localStorage · 无构建无依赖
